# Lessons learned

Short, searchable records of things that surprised us — incidents, costly mistakes, agent
misbehavior, tooling gotchas. Agents check this folder before working in an affected area.

- Lessons: `YYYY-MM-DD-<topic>.md` using [templates/lesson-learned.md](../templates/lesson-learned.md).
- Incidents: `YYYY-MM-DD-incident-<topic>.md` using [templates/postmortem.md](../templates/postmortem.md).
- Blameless: describe systems and decisions, not people.
- If a lesson changes how we work, update the relevant standard (and ADR if needed) and link it.
