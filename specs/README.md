# Specs

Design specs for every repo, written by the Superpowers `brainstorming` skill using
[templates/design-spec.md](../templates/design-spec.md).

- Path: `specs/<repo>/YYYY-MM-DD-<topic>-design.md` (`<repo>` from [repos/registry.md](../repos/registry.md),
  or `cross-repo`).
- Never rename an approved spec; supersede it with a new one and update `status`.
